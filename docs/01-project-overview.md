
# CarePoint Virtual Clinic – Doxy.me Telehealth Implementation

## Project Overview

This project demonstrates the configuration and testing of a telehealth clinic environment using Doxy.me.

The implementation was created for **CarePoint Virtual Clinic**, a virtual outpatient clinic designed to support remote consultations across multiple service areas.

The project focused on configuring a structured telehealth environment, managing consultation rooms, testing patient check-in workflows, conducting video consultations, enabling clinical tools, and reviewing consultation history and analytics.

## Project Objectives

The main objectives of the implementation were to:

- Configure a virtual clinic environment in Doxy.me
- Create individual and shared consultation rooms
- Configure access to shared consultation rooms
- Implement room passcodes for controlled patient check-in
- Test the patient waiting-room workflow
- Conduct a complete test video consultation
- Enable clinical tools for use during telehealth sessions
- Review consultation history
- Review session analytics

## Clinic Structure

CarePoint Virtual Clinic was configured with the following shared consultation rooms:

- General Consultation
- FollowUp Consultation
- Chronic Care
- Women's Health
- Pediatric Consultation

Individual provider rooms were also available for assigned clinic users.

## Telehealth Workflow

The implemented workflow follows this process:

1. Patient receives a consultation room link
2. Patient enters the room passcode
3. Patient completes the check-in process
4. Patient enters the waiting queue
5. Provider sees the patient on the Doxy.me dashboard
6. Provider starts the video consultation
7. Clinical tools can be used during the consultation
8. The completed session is recorded in consultation history
9. Session activity is reflected in analytics

## Clinical Tools

The telehealth environment included access to tools such as:

- File Transfer
- Photo Capture
- Assessments
- Notepad
- Teleconsent
- Payment
- Transcript
- Scribe

These tools support documentation, patient communication, consent, clinical assessments, and other activities during virtual consultations.

## Testing

The telehealth workflow was tested using a non-clinical test participant.

Testing included:

- Patient check-in
- Waiting-room queue
- Video connection
- Audio and video testing
- Live consultation
- Clinical tool access
- Session history
- Analytics reporting

No real patient medical information was used during testing.

## Outcome

The completed implementation demonstrates a functional Doxy.me telehealth clinic environment capable of supporting multiple consultation services, secure patient access, provider workflows, clinical tools, consultation tracking, and operational analytics.
