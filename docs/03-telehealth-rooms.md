
# Telehealth Rooms

## Overview

CarePoint Virtual Clinic was configured with multiple consultation rooms in Doxy.me to organize virtual appointments according to the type of service being provided.

This structure allows patients to enter the appropriate virtual waiting room while giving the provider a centralized view of patients waiting across the clinic.

## Configured Rooms

The clinic was configured with the following shared consultation rooms:

- General Consultation
- FollowUp Consultation
- Chronic Care
- Women's Health
- Pediatric Consultation

An individual provider room was also available within the clinic environment.

## General Consultation

The **General Consultation** room was used as the primary room for testing the complete telehealth workflow.

Testing included:

- Patient access to the consultation room
- Patient check-in
- Entry into the waiting queue
- Provider identification of the waiting participant
- Starting a video consultation
- Accessing clinical tools during the session
- Completing the consultation

## Shared Room Structure

Using separate rooms provides a simple way to organize different consultation types within the same virtual clinic.

For example:

| Room | Intended Workflow |
|---|---|
| General Consultation | Routine virtual consultations |
| FollowUp Consultation | Follow-up appointments |
| Chronic Care | Ongoing chronic care consultations |
| Women's Health | Women's health consultations |
| Pediatric Consultation | Pediatric consultations |

## Patient Waiting Room

When a test participant completed the check-in process, the participant appeared under the appropriate consultation room on the provider dashboard.

The provider dashboard displayed the waiting participant and provided an option to start the video call.

This demonstrated the connection between:

**Consultation Room → Patient Check-In → Waiting Queue → Provider Dashboard → Video Consultation**

## Room Access Controls

Room access can be managed using the consultation link and configured room access controls.

During implementation, the workflow was tested to confirm that a participant could use the appropriate room access information and successfully reach the virtual waiting room.

## Implementation Result

The room structure provides CarePoint Virtual Clinic with an organized telehealth environment where different types of virtual consultations can be managed from one clinic dashboard.

The successful test of the General Consultation room demonstrated that the configured room workflow could support patient entry, waiting-room management, and live video consultation.
