
# Clinic Configuration

## Overview

The Doxy.me environment was configured for **CarePoint Virtual Clinic** to provide an organized workspace for virtual patient consultations.

The configuration focused on establishing the clinic structure, consultation rooms, provider access, patient entry points, and supporting tools required for a practical telehealth workflow.

## Clinic Setup

The virtual clinic was configured to provide a central environment where providers can manage patient consultations.

The setup included:

- Clinic workspace configuration
- Provider access
- Individual provider rooms
- Shared consultation rooms
- Patient waiting-room access
- Consultation links
- Room access controls
- Clinical applications
- Session tracking and analytics

## Consultation Rooms

Multiple consultation rooms were configured to represent different virtual care services.

The clinic included:

- General Consultation
- FollowUp Consultation
- Chronic Care
- Women's Health
- Pediatric Consultation

These rooms provide a structured way to organize patients according to the type of consultation required.

## Room Access

Consultation rooms were configured with patient-facing access links.

Where appropriate, room passcodes were used to provide an additional access step before patients could enter the virtual waiting room.

This created a workflow in which a patient could:

1. Receive the appropriate consultation link
2. Open the virtual consultation room
3. Enter the required room passcode
4. Complete the check-in process
5. Enter the provider's waiting queue

## Provider Dashboard

The provider dashboard serves as the central workspace for managing virtual consultations.

From the dashboard, the provider can:

- View available consultation rooms
- See patients waiting for consultations
- Start video calls
- Access patient interaction controls
- Manage the active consultation
- Access supported clinical tools

## Clinical Applications

The clinic environment was also configured with applications that can support activities during a telehealth consultation.

Enabled tools included:

- File Transfer
- Photo Capture
- Assessments
- Notepad
- Teleconsent
- Payment
- Transcript
- Scribe

These applications extend the basic video consultation workflow by supporting documentation, assessments, consent, file exchange, and other virtual-care activities.

## Configuration Result

The completed configuration created a structured telehealth workspace capable of supporting multiple consultation services from a single Doxy.me clinic environment.

The setup was subsequently tested through the patient check-in, waiting-room, video consultation, clinical tools, history, and analytics workflows.
