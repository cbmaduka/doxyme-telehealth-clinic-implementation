
# Clinical Tools

## Overview

CarePoint Virtual Clinic was configured with Doxy.me applications that extend the video consultation environment beyond basic audio and video communication.

The configured tools can be accessed directly from the consultation interface, allowing supporting activities to remain within the telehealth workflow.

## Configured Clinical Tools

The following applications were made available within the clinic:

| Tool | Function |
|---|---|
| File Transfer | Supports secure file exchange during virtual consultations |
| Photo Capture | Allows images to be captured for appointment documentation |
| Assessments | Provides access to clinical assessment tools during consultations |
| Notepad | Supports private note-taking during a session |
| Teleconsent | Supports digital consent workflows with patients |
| Payment | Provides an option for collecting patient payments |
| Transcript | Provides a written record of an appointment where available |
| Scribe | Supports automated clinical session summarization where available |

## In-Session Access

The applications were made accessible directly from the active video consultation interface.

During testing, the provider could open the clinical tools menu without leaving the video session.

This creates a centralized workflow:

**Video Consultation → Clinical Tools → Consultation Activities → Session Completion**

## Assessments

The Assessments application was added to the clinic and made available during the consultation workflow.

The application provides access to supported clinical assessment questionnaires that can be administered during an appointment.

The implementation focused on configuring and demonstrating access to the assessment functionality rather than documenting real patient responses.

## Documentation Tools

Several available applications support documentation during or after a virtual appointment.

These include:

- Notepad
- Photo Capture
- Transcript
- Scribe
- File Transfer

Together, these tools demonstrate how supporting information can be managed alongside the virtual consultation.

## Patient Administration

Additional applications support administrative components of virtual care.

These include:

- Teleconsent for consent workflows
- Payment for patient payment collection

Their availability demonstrates how administrative activities can be incorporated into the broader telehealth environment.

## Testing Approach

The clinical applications were configured and verified using a test consultation.

The test confirmed that the configured applications appeared within the active video-call interface and were accessible to the provider.

No real patient medical information was entered or used during testing.

## Implementation Result

The configured clinical tools demonstrate how Doxy.me can support a broader virtual-care workflow within CarePoint Virtual Clinic.

Rather than operating solely as a video-calling environment, the implementation provides access to tools supporting assessments, documentation, consent, file exchange, payment, and consultation records from within the telehealth workflow.
